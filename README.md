# StaticDropdown
StaticDropdown
This repository contains example Selenium automation scripts for testing **static dropdowns** using the practice site:  
👉 [Expand Testing Dropdown Practice](https://practice.expandtesting.com/dropdown)

The site provides a simple dropdown menu with options like Option 1 and Option 2.  
- Selecting dropdown values by **index**
- Selecting dropdown values by **visible text**
- Selecting dropdown values by **value**
- Printing selected options to the console
